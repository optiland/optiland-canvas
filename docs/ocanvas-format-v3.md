# `.ocanvas` format, version 3

Version 3 is version 2 ([ocanvas-format-v2.md](ocanvas-format-v2.md)) plus what
real coatings need: a film catalogue with provenance, layers that name their
catalogue entry, materials with a dispersion formula, a form, a source and a
nominal value, a semi-infinite opaque substrate, and the fidelity profile the
scene is traced under. Every addition is optional on read, so a version 3
reader reads version 2 unchanged.

The browser saves version 3. `Scene3::to_json_v2` writes version 2 for older
readers (the optikit-v2 vendored kernel among them) and returns what it could
not say.

## Header

```json
{ "format": "ocanvas", "version": 3, "dimension": 3, ... }
```

`READABLE_VERSIONS` is `[1, 2, 3]`. A version 2 document is migrated to 3 in
memory on read (`crates/oc-core/src/migrate_v2.rs`) and, when the document
layer re-emits it, written back as version 2 exactly as it was read.

## The fidelity profile

```json
"fidelity": {
  "preset": "Standard",
  "coating_model": "Polarized",
  "film_materials": "Dispersive",
  "layer_absorption": "PerFace",
  "plate_model": "PhaseFree",
  "temperature": "Off",
  "numerics": "Permissive",
  "ghosts": null
}
```

Absent when every switch is at its default (`Standard`). `preset` is written
for a person reading the file and ignored on read: the switches are the truth,
and switches that match no preset read as custom. `ghosts` is `null` to leave
the app's ghost setting alone, `0` to turn ghosts off, `n` to follow `n`
generations. See [coatings.md](coatings.md) and the coating-fidelity spec §5.

## Film materials

A film material is version 2's two curves and four optional fields:

```json
{
  "name": "HfO2 (film)",
  "n": { "Tabulated": { "lambda_um": [0.2, 0.228, ...], "values": [2.135, 2.04, ...],
                        "interpolation": "Linear", "out_of_range": "Clamp" } },
  "k": { "Constant": 0.0 },
  "formula": { "formula": { "kind": "cauchy", "coefficients": [1.875, 0.00628, -2, 0.00058, -4] },
               "range_um": [0.2, 2.0] },
  "form": "Film",
  "provenance": {
    "source_kind": "Database",
    "reference": "M. F. Al-Kuhaili. Optical properties of hafnium oxide thin films ...",
    "url": "https://refractiveindex.info/?shelf=main&book=HfO2&page=Al-Kuhaili",
    "license": "CC0-1.0",
    "retrieved": "2026-10-08, the refractiveindex.info database as packaged with Optiland 0.6.1",
    "range_um": [0.2, 2.0],
    "note": "Thin films of hafnium oxide deposited by electron beam evaporation.; k not given; zero"
  },
  "nominal": { "n": 1.9020986954443002, "k": 0.0 }
}
```

- `formula` (optional): a refractiveindex.info dispersion formula for `n`
  (`sellmeier` is formula 1, `sellmeier2` formula 2, `polynomial` formula 3,
  `cauchy` formula 5) and the wavelengths it is valid over. Inside that range
  it replaces the `n` curve; `n` then holds the formula sampled over its
  range, so a reader that knows no formulas still has the index.
- `form` (optional, default `Bulk`): `Film`, `Bulk` or `Crystal`. A film's
  index differs from the bulk's by a few percent, and by process.
- `provenance` (optional): `source_kind` is `Database`, `Measured`, `Nominal`,
  `Digitized` or `Fitted`; the other fields say where the numbers came from.
  A material migrated from a version 2 document is `Nominal`, with the note
  "an inline material from a v2 document".
- `nominal` (optional): the constant `film_materials: Nominal` uses. When
  absent: a constant material's own constant, a tabulated one's value at
  0.55 µm.

## The film catalogue and layer references

```json
"film_catalog": [
  { "id": 3, "material": { "name": "MgF2 (film)", "n": ..., "k": ..., "form": "Film", "provenance": ..., "nominal": ... } }
]
```

A coating layer names its entry with `ref`, and keeps its material inline
beside it:

```json
{ "material": { "name": "MgF2 (film)", ... }, "thickness_nm": 117.75, "ref": 3 }
```

On read, every layer that names an entry takes that entry's material, so the
catalogue is the truth and the inline copy is what a reader that knows no
catalogue reads. A `ref` naming an entry that is not there is refused
(`coating.layers[].ref ... names film catalogue entry 8, which the scene does
not have`). Entry ids are unique.

Reading a version 2 document records each distinct inline material as an
anonymous catalogue entry its layers name. Nothing a coating evaluates
changes: `coating_rt_at` is bit-identical before and after (C30,
`crates/oc-core/tests/film_catalog3.rs`).

The built-in entries the app offers (`filmCatalogJSON`) come from
`crates/oc-core/src/film_catalog.rs`, generated by `tools/ri_import.py` from
the refractiveindex.info database (CC0): MgF₂, SiO₂, Al₂O₃, TiO₂, Ta₂O₅,
HfO₂ and Nb₂O₅ films, ZnS film, MgF₂ at the bulk crystal's ordinary index
(what a hot-deposited AR layer sits near; the database's one MgF₂ film is
44 nm thick and reads 0.04 higher), yttria-stabilized ZrO₂ (crystal: the
database has no ZrO₂ film data), Si, and Ag (two sources), Al, Au, Cr and Ni.
Each table is the source's own numbers between 0.25 and 2.6 µm.

## Coating designs

A coating's `design` records the recipe its layers came from. Version 3 adds
four kinds and an optional `adapt` record:

```json
"design": {
  "kind": "Bbar", "lambda_nm": 550.0, "aoi_deg": 0.0, "periods": 1, "n_high": 2.35, "n_low": 1.38,
  "adapt": {
    "band_um": [0.4, 0.7], "aoi_range_deg": [0.0, 0.0], "substrate_n": 1.5185,
    "materials": [null, null, null], "design_point": [0.0021, 0.9979], "weight": "Uniform"
  }
}
```

| `kind` | Layers |
|---|---|
| `SingleLayerAr` | without `adapt`: a quarter wave of MgF₂ at the constant 1.38; with it: the catalogue film nearest √(n₀ n_s) |
| `VCoat` | two layers with an exact null at `lambda_nm`, or none (the editor names the refusal) |
| `Bbar` | quarter-half-quarter, the inner quarter matched to the substrate |
| `BandAr` | up to 8 layers refined over `band_um` and `aoi_range_deg` |
| `{"EnhancedMetal": {"metal": "Silver", "pairs": 1}}` | the metal under quarter-wave high/low pairs |
| `BroadbandAr` | the old quarter-half-quarter of constant indices, kept as written: nominal, not adapted |

`adapt.substrate_n` is the index the design was solved for, at `lambda_nm`;
`design_point` is R and T there, unpolarized; `materials` names the low,
high and matched films by catalogue key (`"magnesium_fluoride_bulk"`, ...),
`null` for the default; `weight` is `Uniform` or `SunDirect` (ASTM G173
direct). The layers are what the transfer matrix reads; the design is what the
editor re-solves from when the glass changes.

## The opaque backing

```json
"backing": { "Opaque": { "substrate": { "name": "Al", "n": { "Constant": 0.958 }, "k": { "Constant": 6.69 } } } }
```

A semi-infinite absorbing substrate: what the stack transmits into it is
absorbed there. Lit from its film side only.

## Writing version 2

`Scene3::to_json_v2` drops every version 3 addition and lists what that cost:

| Version 3 | Written as version 2 | Loss noted |
|---|---|---|
| `film_catalog`, `ref` | dropped; layers keep their inline material | no |
| a migrated v2 material's provenance | dropped | no |
| any other provenance, `form`, `nominal` | dropped | yes |
| `formula` | the sampled `n` curve | yes |
| `Opaque` backing | 1 mm of the substrate as a last layer, `Medium` backing | yes |
| `fidelity` | dropped; v2 traces as `Standard` | yes, when not `Standard` |
| a `VCoat`, `Bbar` or `BandAr` design | `SingleLayerAr`, layers kept (its reflection stays a ghost) | yes |
| an `EnhancedMetal` design | no design record, layers kept | yes |
| `adapt` on any other design | dropped | yes |
